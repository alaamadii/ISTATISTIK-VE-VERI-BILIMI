# 📊 İstatistik ve Veri Bilimi — YMT2101

This repository contains **Turkish study notes, cheat sheets, formulas, and practical examples** prepared for the **YMT2101 – İstatistik ve Veri Bilimi** course at **Fırat University, Software Engineering Department**.

The materials are organized to help students review key concepts, understand algorithms, and prepare for exams.

## 📚 Contents

1. **Veri Bilimine Giriş** — Fundamental concepts and data science methods.
2. **Veri Madenciliği** — Data preprocessing, normalization, and data mining techniques.
3. **Karar Ağaçları** — ID3, C4.5, entropy, information gain, and decision rules.
4. **Sınıflandırıcı Değerlendirme** — Confusion matrix, accuracy, precision, recall, and F1-score.
5. **K-En Yakın Komşu (KNN)** — Distance calculations, classification, and weighted voting.
6. **Uygulama ve Formül Özeti** — Essential formulas, worked examples, and exam revision.

## 🎯 Purpose

To provide a simple, structured, and accessible reference for students studying statistics, data science, and machine learning fundamentals.

> **Note:** These are student-prepared study materials, not official Fırat University course documents. They are intended for educational and exam preparation purposes.
